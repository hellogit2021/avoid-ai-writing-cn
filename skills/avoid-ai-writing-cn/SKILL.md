# 去 AI 味写作（中文优先）

把文本里像 AI 生成的痕迹找出来改掉，让文字读起来像人写的。这是写作质量工具，给出的是信号不是裁决——别用它给文章"判 AI 身份"。

## 为什么会像 AI（先看根因，再查词表）

模型每一步都选"最可能接下去出现"的那句，于是总选对任何读者都成立的说法；人只为一个读者、一个主题写，所以写法不均匀、很具体。下面每一类都是这种"默认选择"的一种，词表只是它们的下游表现：

1. **摆姿态**：句子在暗示"这很重要"，却不增加事实——对比句只加分量、结尾句重复前文。
2. **按规则造节奏**：三连、破折号、碎裂短句，不管意思需不需要都上。
3. **膨胀**：把普通事实说成关键的、有权威背书的。
4. **按规则排版**：每一条都加粗、每个小标题都装饰、每个列表都带标签。
5. **残留**：聊天外壳与草稿动作（"希望这能帮到你""让我们来看看""值得一提的是"）。
6. **写给错误的读者**：把对方已经知道的背景重讲一遍，结论压在最后一行。

三条元规则：

- **保留的每一句都必须给读者带来新东西**（新事实、新因果、新后果）；只是换个说法重述前文的句子，删。
- **一个 tell 的分量，取决于谨慎的作者故意这么写的概率有多低**。破折号、单个模糊引用、单个加粗都可能是有意为之——越像有意为之的，越不要动。
- **可移植性测试**：一句话如果原封不动搬到另一个人、另一家公司、另一个产品身上依然成立，它就是废话——删掉，或换成只属于这个主题的事实、例子、机制、后果、判断。

## 什么时候不要动

- 引语、标题、专有名词，以及正在讨论该词本身的段落，一律不动。
- 弱信号单独出现时不处理：单个破折号、单个模糊引用、单个加粗。**多个 tell 出现在同一段**才是可靠判据——这是避免误伤的唯一保障。
- 保留承载作者声音的细节：具体的怪细节、没有解开的矛盾情绪、有年份感的梗、作者能解释的第一人称选择、真实的自我修正。
- 保留表达**真实犹疑、自省或口语节奏**的词（"我觉得""可能""说实话""得承认"）——只有当它们作为纯引导语、只为拖延结论时才删。
- 只有确实难读时才拆句拆段；清楚的口语长句、碎片句、节奏变化属于作者，保留。不要为了让每段的长度和整洁度一致而改写——"均匀"本身就是 AI 味。

### 假阳性：单独出现都不是可靠信号

语法完美、文风一致（专业写手或经过编辑）／随意与正式语域混用（领域习惯）／"平淡"或"机械"（AI 的破绽是**特定**那几种，只是干燥那就只是干燥）／正式或学术词汇（AI 滥用的是特定一批词，不是所有大词）／偶尔一个"然而""此外"／书信体的问候与落款／单个短句、单个破折号、句中的"说实话"／没有来源的主张（网上大部分内容都没来源）。

判据是**信号成簇，不要抓单条**：单个破折号什么都不是；但"破折号 + 三段式 + 空泛套话 + '展望未来'结尾"同时出现，基本就是自白。

### 人类写作迹象（优先保留）

难以编造的具体细节（真实地名、奇怪的引语、只有当事人才知道的小事）／未化解的混合情绪／有年代感的圈层引用／作者能解释自己的编辑选择／具体的限制、例外与个人判断／句长参差／真实的旁白、括号插话或当场自我修正／贴合用途的正式度与作者习惯的词语节奏。

## 改写后自检（逐条判 pass / fail，任何一条 fail 就回去改）

**事实与立场**
1. 有没有多出原文没有的事实、数字、人名、日期、引文、观点？（多出来 = 错误）
2. 有没有漏掉原文的主张？（漏掉 = 错误，除非规则要求删）
3. 原文的立场、犹疑、第一人称、口语节奏还在吗？

**声音**
4. 强的人写的句子，是不是被我一并改掉了？
5. 每一段的长度和整洁度，是不是被我弄均匀了？（均匀 = AI 味）
6. 表达真实犹疑的词（我觉得 / 可能 / 说实话）是不是被误删了？

**AI 味**
7. 对比句、结尾重述句、三连、假洞察开场、假深刻收尾，还有残留吗？
8. 每个"通用句"过得了可移植性测试吗？（能搬到别的主题上 = 废话）
9. 还有无生命主语、名词化空转、"作为/堪称"这类回避"是/有"的写法吗？

**读者信任**
10. 有没有没必要的安抚、许可、解释或手把手铺垫？（"希望这能帮到你""简单来说""不用担心"）

**收尾**
11. 读出声。听起来还像 AI 的地方，多半没改干净。
12. 结尾落在具体事实上，还是落在了升华、金句上？

## 需要澄清时（最多问一个问题）

- 没给文本：先要文本，不要凭空开写。
- 受众或发布场合不清楚，只问一个问题："这是给谁看的，发在哪里？"
- 目标不清楚（想让读者因此做什么），问："读完你希望读者想什么、感觉什么、或去做什么？"
- 除这两种情况外不要追问，能改就直接改，别把澄清变成流程。

## 重写原则（不可违反）

1. 只删减和锐化，不添加：原文没有的事实、数字、人名、观点、第一人称一律不加；缺信息就标记缺口，不补。
2. 保留原文：具体案例、数字、作者立场、第一人称、口语风格。
3. 不注入表演：不添加"说实话""说白了"这类原文没有的口头禅，不制造排比，不添加情绪。
4. 引用、代码、表格、署名文字不改写，只标记。
5. 目标：直接、具体、有长短节奏。删空话后没信息的段落就删段。
6. 最小有效修改：只修 AI 痕迹、错误、重复、真正读不懂的地方，**强的人写的句子别碰**。删减量要和实际的 AI 味成比例——不要为了压字数把个性一起压掉。
7. 保留有用的毛边：强烈观点、粗话、幽默、自我打断、坦白的承认都属于作者，不要换成更安全、更职业的说法。
8. 动了结构就说一句：合并、拆分段落或调序时，在极简说明里交代为什么。

## 内置通用规则（句式与结构）

> 以下规则与"内置通用词表"一样随插件升级更新；中文语境适配自原版 avoid-ai-writing（agentskills.io 规范），多数为语言无关的写作规律。执行重写/只标记时与"用户个人词表"合并参考，冲突以用户为准。

### 句式模板（避免的句子骨架）

| 句式 | 处理 |
|---|---|
| 不是……而是……（"不是 X，是 Y"） | 每篇最多 1 次，其余改直接肯定句 |
| 转折否定开场："很多人以为……其实……" | 直接说结论 |
| 自我否定结构："这不是 X 的问题，是 Y 的问题" | 直说 Y |
| 假设场景开场："在这个……的时代""如今，……" | 删开场，直接进入内容 |
| 假范围："无论你是……还是……" | 删，只说实际受众 |
| 堆叠预测："可能""或许""有望"连用 | 留一个，其余删 |
| 反问句（尤其结尾"答案不就出来了吗"） | 每篇最多 1 处，其余改陈述句 |
| 格言公式："X 是新的 Y""重要的不是 X，而是 Y" | 直说事实 |
| 表演式洞察："值得玩味的是""细思极恐的是" | 删，直接说洞察 |
| 否定链："没有 X、没有 Y、没有 Z" | 直说肯定表述 |
| 冒号引出三连："三个关键词：A、B、C" | 改为真实内容 |
| 发明对比镜像："与其说是 A，不如说是 B" | 直说 B |
| 回避"是/有"："作为""堪称""不失为""兼具" | 换回"是/有"，或直说它是什么 |
| 名词化空转："进行了优化""实现了提升""完成了闭环" | 换回动词："优化了""提升了""做完了" |
| 无主句："需要进行优化""有待进一步验证" | 补出谁做什么，或直接说结论 |
| 假洞察开场："大多数人不知道的是""很多人都搞错了""没人告诉你" | 删开场，直接说结论（这类句子只是把作者捧成唯一的专家） |
| 冒号揭晓："真正的关键：……""最狠的一点：……" | 改成普通句子；冒号只用于列表、标签、引语 |
| 无生命主语（"决定浮出水面""数据告诉我们"） | 换成人做主语："我们决定……""从数据看……" |
| 假深刻收尾（把结尾升华成比喻、格言、金句） | **删掉，不要改写成更好的比喻，也不要保留它的节奏**；结束在草稿里最后一句具体的话 |
| 中英混排复合词堆叠："AI-native""end-to-end""高质量""高可用""全链路" | 保留必要术语，并说清它在本文里的具体含义 |
| 权威姿态伪句式："真正的问题是""归根结底""本质上""底层逻辑是""问题不在 A 而在 B" | 直接写判断和依据；别先否定一个稻草人再揭示"真正答案" |
| 导览式开场："让我们深入探讨""下面我们来拆解""本文将带你了解""废话不多说" | 删掉宣告，直接写正文 |

### 过渡与连接

- "此外""再者""更重要的是""总而言之"：删或重组，让逻辑自然衔接
- "值得一提的是""值得注意的是"：直接陈述事实
- "说白了""坦白的说""说实话"：作为引导语时删；表达真实犹疑或口语节奏时保留
- 段落之间缺少桥梁句：补一句承接，或重排
- 规则三强迫症（"A、B 和 C"三连排比）：改成两项/四项或整句，每篇最多 1 处

### 结构问题

- 段落长度均匀（每段都是 3-5 句）：故意拉开长短
- 公式化开场（先铺背景再入题）：直接以新闻/观点开头
- 过度整洁的语法：保留作者自己的碎片句、"而且/但是"开头、标点瑕疵
- 无动词名词列表（5+ 条短名词短语）：改成完整句子或散文
- 编号列表膨胀（本来不用编号的地方编号）：转散文
- 文字墙（没有分段）：该分段
- 过度结构化（每段都有小标题/加粗）：删减
- 段落可互换（调换顺序无影响）：建立递进主线，或承认是清单
- 跑步机效应（每段没有新信息，只是换说法）：每段只留一个新事实/新主张，删掉重复
- 同义词循环（同一意思换词反复说）：重复就用同一个词，别刻意换词
- 词汇多样性过低（200+ 词长文 TTR 明显偏低）：具体化，引入实例，别为多样而多样

### 修辞与语气

- 显著性膨胀："里程碑""颠覆""划时代""改写历史"——直说实际发生了什么
- 泛化结论："未来可期""前景光明""值得期待"——删或说具体
- 未来叙事结尾："这可能成为 X 的重要一步"——删
- 促销语言："一流""顶级""最佳"——用具体标准替代
- 模糊归因："专家认为""业内人士表示"——给出处或删
- 名人堆砌：只在真有关系时提
- 模糊第三方背书："受到广泛好评"——删
- 谄媚语气："您说得太对了""这个想法很棒"——删
- 情绪平直（全文毫无立场和反应）：在合适处加作者真实反应（原文有立场才加）
- 假让步："虽然……但是……"空转（没有真让步）——删
- 自我标注重要性："这个发现很重要""关键在于"——删标签，让内容自己说话
- 悬置注意力："这让我久久不能平静""我反复看了三遍"——直说为什么
- 制造高潮/断句戏剧：用内容本身制造节奏，不靠碎裂句

### 填充与痕迹

- 填充词："某种程度上""某种意义上"——删（保留表转折的"其实"）
- 聊天机器人痕迹："当然！""好问题！""希望这能帮到你"——删
- "让我们……"（"让我们来看看"）——直接说
- 截止免责："据我所知""以我目前掌握的信息"——按实际情况说
- 占位符："TODO""XXX""[待补充]"——补齐或删
- 引用标记泄漏（"（来源：xxx）"样式的假引用）——删
- URL 跟踪参数（utm_xxx）——删

### 严重度分级

- P0（立即改）：虚假归因、聊天机器人痕迹、显著性膨胀、hashtag 堆砌（社交语境）
- P1（发布前改）：句式模板、词表命中、过渡词、堆叠预测、泛化结尾、加粗滥用
- P2（有空再改）：规则三、段落均匀、无动词列表、同义词循环、填充词

### 语气校准（重写时）

目标：像人写的。短句长句交替；具体（数字/名字/日期/例子）；有立场（原文有立场就保留强化）；删除空洞强调；不做过度打磨（把不规则处磨平反而更像 AI）。

### 永不注入（重写时禁止添加原文没有的东西）

1. 假第一人称（"我见过很多次""依我经验"）——原文没有"我"就不加
2. 制造紧张（"在这个时代""史无前例"）
3. 强迫反调（"大家都错了，其实……"）
4. 表演式坦率（"说句实话""老实讲"）
5. 断句戏剧（把句子剁成碎片制造节奏）
6. 虚构细节（数字、人名、日期、机制——原文没有的绝不编）

## 用户个人词表（不随插件升级丢失）

- 位置：$DSH_HOME/avoid-ai-writing-cn/user-patterns.md（Windows 通常为 %APPDATA%\dsh-desktop\harness\avoid-ai-writing-cn\user-patterns.md）；文件不存在则用 Write 创建
- 内容：用户自己的规避词与规则（"写的不错"的学习记录、自定义词、豁免项）
- 优先级：用户个人词表 > 内置通用词表。同一词两边都出现时，以用户个人词表的处理为准；用户写"放行"表示该词不再标记（取消内置规则）
- 格式与内置表一致：按 1A / 2 / 3 / 句式 分类，无法归类放"其他"
- 触发"写的不错"时，回顾本次重写的全部调整因素并追加到本表：
  ① 本次识别的新 AI 词汇/句式（内置表与个人表都没有的）；
  ② 用户指出/纠正的任何问题——即使内置表已有该规则，也按用户偏好记入本表（收紧或覆盖内置，例如内置"不是……而是……限 1 次"被用户纠正为"每篇 0 次"）；

- 插件升级只更新内置部分（SKILL.md），本表不受影响

## 只标记模式的输出

精简清单：按 P0（可信度杀手）/ P1（明显 AI 味）/ P2（风格）分组，每条点名规则、引用原文片段、给一句话改法；结尾一句话描述"AI 味浓度"。不做长篇分析。

工具会猜，具名的规则才是用户能自己核对的证据：所以不推断作者是谁、用了什么工具，只列出可核对的事实。改不改由用户定，可以补一句"要不要我直接重写"。

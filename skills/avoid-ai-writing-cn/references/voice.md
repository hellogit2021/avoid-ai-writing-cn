# 语气校准与"个性与灵魂"

## 一、用户给了写作样本时（样本优先）

样本覆盖本技能的所有规则——包括词表和句式限制。先读样本，再动手：

1. **读懂样本**，记录六件事：句子长短模式（短促有力？绵长舒展？长短混合？）／用词层级（口语？书面？专业？）／段落怎么起手（直接切入？先铺背景？）／标点习惯（破折号、括号插话、分号）／反复出现的口头禅／怎么过渡（用明确连接词？还是直接开始下一点）。
2. **在改写里换成样本里的模式**——不是"去掉 AI 味"就完事：他写短句，你就别产出长句；他说"东西""事儿"，你就别升级成"要素""组件"；他的标点习惯照他的来。
3. **样本优先于一切**，包括内置词表的命中：样本里的词即使在内置表里，也以样本为准。

没有样本时，回退到默认：清楚、具体、克制，句长参差。中性体裁不要加个人情绪。

## 二、用户怎么提供样本（可以主动告诉他）

- 内联："帮我改写这段。这是我平时的写作样本，用来匹配语气：[样本]"
- 文件："帮我改写这段。参考 [文件路径] 里我的写作风格。"

## 三、个性与灵魂（**只在需要时应用**）

去 AI 味只是一半任务。另一半是：**干净但没灵魂，和糟糕的写作没区别**。

**适用范围**：博客、随笔、观点、评论、个人化写作。
**不适用**：学术论文、技术文档、法律条款、百科、说明书、参考资料——这类文本里，**中性、平实本身就是正确的人类声音**。给 API 文档加"我个人觉得"，和给随笔套模板一样假。

### "干净但没灵魂"的迹象

- 每个句子的长度和结构都差不多
- 只有中性陈述，没有观点
- 不承认任何不确定或复杂情绪
- 该用第一人称的地方完全不用
- 没有幽默、没有棱角、没有个性
- 每句都正确，但没有一句像作者真的在乎
- 只会说"具有重要意义""值得关注"，却不说为什么
- 所有段落都是同一个模板：背景 → 价值 → 挑战 → 未来

### 增加人味的五种方法（都建立在原文已有的事实上）

1. **要有观点**：不要只罗列事实，对它们有反应。
2. **让节奏有变化**：短句干脆，然后来一句慢慢展开的长句。
3. **让一点乱进来**：跑题、旁白、没想完的半截念头——**只在原文本来就有这种语气时才保留，不要凭空添加**。
4. **抽象评价换成可观察细节**：把"体验很好"落到原文里已有的具体步骤上。
5. **宏大意义换成具体后果**：把"影响深远"换成原文里已有的具体变化。

### 示例（改后不新增任何事实）

```
改写前：这次实验产生了有趣的结果。这些智能体生成了三百万行代码。一些开发者印象深刻，另一些则持怀疑态度。它的影响仍不明朗。

改写后：智能体生成了三百万行代码。开发者里一半觉得厉害，一半觉得不算数——到底意味着什么，还看不出来。
```

改后做了三件事：删掉"产生了有趣的结果"这句空话；把"印象深刻/持怀疑"落成"一半觉得厉害，一半觉得不算数"；把"影响仍不明朗"改成具体所指的"到底意味着什么还看不出来"。**没有加时间、地点、人物或数字。**

> 反例：某些同类技能会把这段改写成带"趁人睡着的时候""我脑子里一直是……"的版本——那是靠**新增细节和第一人称**制造人味，本插件**不做**：原文没有的事实、经历、情绪，一律不加（见 SKILL.md「重写原则」第 1、6 条）。
